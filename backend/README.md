# Backend

FastAPI application for the Orders, Payments, and Reconciliation platform. It exposes the REST API, owns the PostgreSQL schema through Alembic migrations, and contains the backend tests.

> **Status:** not started. This folder is a placeholder created by [#5](https://github.com/gabrielkrneiro/pedidos-pagamentos-conciliacao/issues/5).

## Tech stack

| Concern     | Technology        |
| ----------- | ----------------- |
| Language    | Python            |
| Web framework | FastAPI         |
| Database    | PostgreSQL        |
| Migrations  | Alembic           |
